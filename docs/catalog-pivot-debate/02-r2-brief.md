3. **셀프 리플렉션** — 내 r1 의 약점, 다른 사람 안을 보고 바꾼 것.
4. **수정한 최종 상위 3** — 무엇 · 지표 · 비용(일) · 누가.
5. **통합 일정 제안 한 줄** — 10/5 ~ 10/14 사이 무엇을 언제 낼지.
