## 3. 셀프 리플렉션

1. **표본 크기를 계산하지 않았다(가장 큰 실수).** 01-metrics 의 "100 미만 경고"를 읽고도 한 번뿐인 트래픽을 둘로 나눴다. 기준선과 비교 둘 다 판정 불가가 될 설계였다.
2. **"코어 데이터는 그림과 무관"이 피봇 범위를 과소평가했다.** 코어 루프는 고정이지만 목표 깊이 · 판 구조(Time Gates)가 바뀌면 퍼널도 바뀐다.
3. **첫 30초를 v0.9.1 에 끼워 넣자는 안은 일정 압박만 만들었다.** 트래픽이 안 가는 빌드에 서둘러 넣을 이유가 없다.
4. **"목표가 안 보인다"(디자인)와 "커버 ↔ 로비 불일치"(AD)를 놓쳤다.** 내 첫 30초 안은 손가락 · 연출만 봤다. 둘을 합쳐 최종안 1 로.
5. **유지:** 좋아요는 게임 밖 버튼이라 입력 없는 정점에서 눌린다는 설계, LH like/play 는 챌린지 특수 유입이라 장치 효과로 못 본다는 판단(운영도 "표가 바뀐 것일 수 있다"로 같은 결론), Daily 를 없애면 재방문 장치가 0 이 된다는 지적.
