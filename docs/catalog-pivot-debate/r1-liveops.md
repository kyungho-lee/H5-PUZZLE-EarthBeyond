### 2-2. LH 가 증명한 것 / 못 한 것

| 구분 | 내용 |
|---|---|
| **최신(10/2, 운영)** | **142 played · 18 likes(≈ 12.7%) · 챌린지 1위.** EB 는 3 played. 캐비닛 화면(LH 추정): 세션 183 · 바운스 62.8% · 평균 17분 21초(표본 < 100 경고) · 5분 이상 25세션. 기간 필터가 캡처에 없어 공개 played(142)와 캐비닛 Plays(68)의 시점이 다르다 |
| **관찰된 사실** | SHARE 링크 2개 · 약 32시간에 **101~103 plays**(예산 $4 중 28.6% 소진). 게임 안 SaaS 리더보드에 실제 기록이 쌓임(v0.2.0 시점 10건). 캠페인 도중 **리비전을 9번 바꿔도 캠페인은 계속됐다**(v0.1.1~v0.2.4). 링크를 더하면 기간이 늘어난다 |
| **like/play ≈ 10~13% 의 의미** | **LH 만의 성과라고 보기 어렵다**(10/2 기준 18/142 ≈ 12.7% 로 1위가 됐어도 같은 판단). 10/1  같은 챌린지 표: 1위 7.5%(202/2.7k) · 2위 25%(16/64) · 3위 8%(12/150) · 5위 14%(6/42) · 6위 7.5%(5/67). 챌린지 출품작 대부분이 **7~25%** 구간. 챌린지 탭을 보는 사람(참가 개발자 · 챌린지 구경꾼)이 좋아요를 잘 누르는 **특수 유입**일 가능성이 크다 |
| **장치별 기여** | **측정 불가.** 좋아요 시계열이 없다(LH 자체 스냅샷 1회, 10/1). 순위 화면(v0.1.4) · 엔딩(v0.2.0) · 띠(v0.2.2) 가 모두 트래픽 첫 36시간 안에 연달아 들어가, 무엇이 좋아요를 불렀는지 분리할 수 없다 |
| **평균 17분의 의미** | 소수의 긴 세션이 끌어올린 값. 5분 이상은 game ready 의 **15%**(25/168)뿐이다. LH 도 "대부분은 30초 안에 떠난다"는 문제를 풀지 못했다 → EB 가 이 숫자를 목표로 삼으면 안 되고, **깔때기 비율**을 목표로 삼는다 |
| **못 한 것** | 첫 30초 이탈(60%) · 재방문(D1/D7 아직 —) · 표본 신뢰도(< 100) · 챌린지 밖 일반 샌드박스에서의 좋아요 · 이벤트 뒤(11월) 수명 |

### 2-3. LH 와 EB 의 다른 점 (라이브옵스)

| | LH | EB |
|---|---|---|
| 유입 | 챌린지 탭 + SHARE. 좋아요가 **보이고 순위가 됨** | 일반 샌드박스 + SHARE. 좋아요 **숫자가 안 보임** |
| 수명 | 10/6 마감 · 할로윈까지 | 카탈로그 = 상시. 선발 시점 미정 |
| 귀환 이유 | 필요 없음(1주 승부) | **필수** — 카탈로그 성과는 날이 갈수록 쌓여야 함 |
| 범위 | 6일 · 1테마 | 누적 3시대 · Daily · Endless |

## 3. 방향 투표 — **C** (컨셉 · 세계관 유지, 그래픽 제작 방식 교체 + 시나리오 압축, **같은 앱 id**)

| 이유 (라이브옵스) | |
|---|---|
| 지구사 · "138억 년"은 **상시형 훅**이다 | 시즌이 지나도 낡지 않음. 장면마다 "몇 년 전"이라는 이름이 붙어 발견 = 작은 지식 보상 → 좋아요 정점의 재료. 반려 사유는 컨셉이 아니라 **AI 그림 · 신선함**이었다 |
| 시즌/이벤트형 피봇은 카탈로그 선발에 **불리** | 선발 시점을 모른다. 할로윈형이면 11월에 뽑혀도 철 지난 게임. 같은 조직 · 같은 엔진의 LH 와 **할로윈이 겹친다**(자기 잠식). 시즌마다 테마 교체 = 매달 아트 한 세트(코드 아트) 비용 |
| 대신 **시즌 레이어**는 유리 | 상시 컨셉 위에 "이달의 장면 · 오늘의 역사" 같은 얹는 층 → 귀환 이유. 제안 5 · 5위 밖 이벤트 장 |
| **같은 앱 id** | 샌드박스 지정(Playgama 가 직접 옮김) · plays/likes 누적 · SHARE 자격("once per game")을 그대로 쓴다. 새 앱이면 SHARE 를 새 앱에 써야 하고, 조직 남은 2개 중 보존분까지 건드리게 됨 |

> 조건: AD · 디자인이 "AI 그림 없이 지구사 33장면을 손/코드로 낼 수 없다"고 보면 **B(상시형 새 컨셉)** 로 간다. 그때도 **할로윈 · 시즌 단독 컨셉은 반대**.

| 안 | 구조 | 카탈로그 유불리 |
|---|---|---|

| 0~3 | 무작위 2칸 보드 + 글자 토스트 3.6초 | **보드 위 손가락 스와이프 애니메이션**(글 없음, 첫 수에 사라짐) | 광고 유입자는 글을 안 읽는다. 로딩은 문제 아님(LH ready 91.8% · 0.2초) |

측정: 캐비닛 깔때기의 **30초 생존(30s+ / game ready)** 하나로 판정. 다른 변경과 같은 게시에 넣으면 분리가 안 되니, 넣는 게시본을 리포트에 적는다.
