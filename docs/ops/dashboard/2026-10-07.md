3. **표본 부족 · 이상치**: 리텐션 분자 7명, 모바일 plays ≈15. 평균 플레이 시간은 긴 세션 몇 개에 좌우(텔레메트리 시퀀스 최대 59183초 · 100606초 · 17020초가 날짜별로 존재 — 탭을 열어 둔 세션으로 보임). 10/5~10/6 시퀀스 평균 521초는 이상치 한 개를 빼면 약 383초로 내려간다 【계산】.
4. **모바일 미검증**: plays 의 7%. 모바일 체류가 짧아 보이지만 표본이 없어 판정 불가. 하단 방향 패드 제거(v0.9.2)가 모바일에 어떤 영향인지 이 데이터로는 모른다.
5. **성능 텔레메트리 비어 있음**: 세션 요약 `observed_sessions: 0` · `telemetry_coverage: 0` · fps null — 성능 샘플이 수집되지 않는다(null 은 0 이 아니라 미관측). 기술총괄에게 확인 필요(제안).
