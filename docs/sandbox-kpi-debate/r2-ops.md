## 0. r2 에서 새로 확인한 사실 (출처 원문)

1. **Bridge 2.3.0 은 2026-09-30 에 나왔다**(changelog). 포함 내용: `analytics.send(name, data)`, "**`gameplay_30s` and `gameplay_60s` are sent automatically after `game_ready`, time on pause is not counted**", "**The first interstitial can be shown 30 seconds after start instead of 60**".
2. **CDN 태그 문제 아님 — 코드 수정 불필요.** setup 문서: "CDN is the recommended option. It always serves the current stable build". EB 는 이미 `https://bridge.playgama.com/v2/stable/playgama-bridge.js`(index.html:19)를 쓴다. 9/29 아카이브의 "2.2.0" 은 2.3.0 출시 **전날** 측정값이다. 지금 샌드박스는 2.3.0 을 받고 있을 가능성이 높다(**미실측** → v0.9.1 QA 에서 콘솔로 확인). 필요한 코드는 `analytics.send` 호출부뿐이고, 기능 검사(`bridge.analytics && bridge.analytics.send`)로 감싼다.
3. **반대로 위험**: stable 이 우리 배포 없이 바뀌었다. 첫 전면광고 지연이 60→30초가 됐고, 광고 실패 팝업 문구도 달라졌다. 이 변경은 **이미 라이브 동작에 들어갔다**(추정). config 의 `advertisement.minimumDelayBetweenInterstitial`(config 문서 예시)을 EB 는 쓰지 않는다 → 광고 간격을 **설정 1줄로 명시**해야 SDK 갱신에 흔들리지 않는다.
4. Bridge 2.1.0: "`bridge.gameVersion` — reported as `game_version` in every analytics event". EB 는 설정하지 않는다(grep 0건). `APP_VERSION` 을 넣으면 Playgama 데이터가 **리비전별로 나뉜다**. r1 에서 걱정한 「혼합 표본」을 플랫폼 쪽에서 해결하는 장치다. 설정 방법(속성 대입인지 설정 파일인지)은 문서에 없다 → 기술 확인.
5. 결론: 플랫폼은 이미 **세션 시작/종료 · 30초/60초 체류**를 자동 수집한다. 「performance metrics」의 재료는 우리가 손대지 않아도 쌓인다. 우리가 할 일은 그 숫자를 올리는 것이다(첫 30초 · 진행 벽). 계측 추가는 보조다.

## 2. 셀프 리플렉션 (내 r1 의 약점)

1. **핵심 루프가 벽인 것을 못 봤다.** 나는 「먼저 측정하고 고친다」를 주장했다. 하지만 D1 sim(1장 클리어 0%)이 나온 이상, 그 순서는 **평생 1회 부스트를 깰 수 없는 빌드에 쓰자**는 말이 된다. 측정 창 동결 논리를 그대로 따르면 결론은 반대다. **큰 게임플레이 수정은 창 앞(v0.9.1)에 넣어야 한다.**
2. **v0.9.1 을 「설정 패치 = 저위험」으로만 설계했다.** 위험을 줄이려다 KPI 효과가 없는 패치가 됐다. 운영의 몫은 위험 0 이 아니다. 위험을 게이트(go/no-go · QA · 동결)로 관리하는 것이다.
3. **Bridge 버전을 잘못 짚었다.** 「2.3.0 으로 올려야 analytics 를 쓴다」고 썼지만, CDN stable 이 자동으로 받는다. 놓친 것도 있다. stable 갱신으로 **우리 배포 없이 광고 타이밍이 바뀌었고**, `gameplay_30s/60s` 가 자동 수집된다. 내 r1 의 A2류 「시간 대리 리더보드」는 필요 없어졌다.
4. **#10 을 「회색」으로 두고 r2 로 넘겼다.** 3명이 같은 지점을 짚었다. 운영(체크리스트 담당)이 판정해야 할 일이었다 → **위반 위험으로 판정, v0.9.1 에서 제거.**
5. 커버를 「make-cover 재촬영」으로 제안했다. AD 가 지적했듯 그 스크립트 자체가 문제(3분할 콜라주)를 만든다. 커버 구성은 A3 를 따른다.
6. 지킨 것: 부스트 평생 1회(게임당) · LH 와 캠페인 비중첩 · 재제출 보류 · 리비전 기록. 이것은 유지한다.
