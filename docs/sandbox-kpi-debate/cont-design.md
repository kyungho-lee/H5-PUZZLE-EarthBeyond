## 0. 결론 먼저

1. **지금 v0.9.1 로컬 빌드로는 엔딩 도달 0%다.** 지층이 1장에만 있어서 2장(`collectionGradedTiers(1)`)의 판당 클리어가 봇 3종 모두 **0%**다. 1장을 깬 플레이어 76~82%(typical)가 첫 세션 안에 2장 벽에 닿는다. CONTINUE 를 어떻게 설계해도 이 벽은 풀리지 않는다 → **지층을 3장 모두에 켜는 것(S3)이 CONTINUE 논의의 전제다.**
2. **광고 CONTINUE(B)는 넣을 이유가 없다.** 첫 판에서 별을 중앙 33개 벌고, 75%가 5⭐ 이상을 번다. 그래서 2판째부터는 별 CONTINUE 가 사실상 늘 보인다. 광고가 실제로 차이를 만드는 곳은 **게임 첫 판(별 0)** 하나뿐이다. 거기에 **무료 1회(C)**를 주면 B와 수치가 같다(아래 표 B = C). #10 위험만 지고 얻는 것이 없다.
3. **추천 = REC**: 지층 창 **6/7/7**(장별) + 별 CONTINUE(5⭐ · 판당 1회, 현행) + **게임 첫 판만 무료 CONTINUE 1회** + **조용한 연패 보정(F)** + 게임오버 화면 E. 체크포인트(D)는 넣지 않는다.

### 읽는 법
- **엔딩까지 시간(1순위 기준)**: NOW 0% → REC 는 typical 44분 · 초보 77분, 60판 안 100%. 엔딩이 "닿을 수 있지만 한 세션으로는 안 되는" 거리(typical 첫 세션 25분 → 2세션)다. 재방문 1회를 만드는 길이다.
- **첫 세션 길이**: A/B/C/D/F(6/6/6)는 16~18분인데 REC 는 **25분**이다. 2 · 3장의 창 7은 한 판이 길고(수가 많고) 판마다 새 장면이 나와 무소득 판이 적다. 지금 기준선(NOW 20분)보다 길다.
- **난이도 의미(4순위)**: 6/6/6 + 별이면 2 · 3장 판당 71~83%다. 장마다 1판이면 끝나서 "깼다"는 느낌이 약하다. 6/7/7 이면 2 · 3장 판당 33~35%로 1장 게이트(25~45%) 범위에 다시 들어온다. 창 7만 쓰고 보정이 없으면(A7) 초보 엔딩이 10%로 무너진다 → **F 가 6/7/7 의 안전망**이다.

## 2. 선택지별 판정 (디자인 + 인지심리, 실제로 해당될 때만)

| 안 | 판정 | 근거 |
|---|---|---|
| A 별 CONTINUE(현행 5⭐ · 판당 1) | **유지** | 2판째부터 늘 보인다(첫 판 별 33). 게임오버에서 "판 보드를 잃는다"는 **손실 회피**를 내가 번 재화로 덜어 준다. 상한 1이 없으면 난이도가 무너진다(지층 gate 2-2). |

**피크엔드**: REC 에서 첫 세션 안에 1장을 깨는 비율이 typical 92% · 초보 69%다(NOW 76% · 40%). 첫 세션의 끝이 "장 클리어 연출 + 2장 첫 장면"이 될 확률이 높아진다. 다만 NOW 는 그 직후 2장 벽(0%)이 첫 세션의 **끝 인상**이 된다 — S3 가 빠지면 피크엔드가 오히려 나빠진다.

- **동결 제약**: 10/5 게시 뒤 10/12까지 규칙을 바꿀 수 없다. S3 를 빼고 게시하면 측정 창 전체가 "2장 0% 벽" 빌드의 기록이 된다. **최소한 S3(6/6/6, 0.5h — `CHAPTERS` 에 2개 추가)만이라도 v0.9.1 에 넣기를 권한다.** 6/7/7 · F 는 위 표대로 sim 근거가 있지만, 시간이 없으면 v0.9.2 로 넘긴다.
- **위험**: ① 2 · 3장의 창 7은 한 판이 길다(분당 수 실측 전). ② F는 "몰래 쉬워짐"이 들키면 성취감을 깎는다 → 한 단계만, 표시 없이, 클리어하면 해제. ③ 세션 모델은 가정이다 → 측정 창의 `run_ended`(moves · duration_sec · max_step) · `clearRuns` 로 확인한다.
