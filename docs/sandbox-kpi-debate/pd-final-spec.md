## 2. v0.9.1 스펙 — 10/5 게시 (합계 약 30h, 10/2~10/4)

### 2-1. 지층 최소판 (디자인 설계 · 기술 구현, 6~12h)
- 1장만: 새 최고 장면이 나오면 `최고 >> 6` 미만 칸을 화석으로 정리(기존 클리어 연출 재사용), 생성 크기 상승. 엔진 기본값은 꺼짐 → 기존 baseline 테스트 불변.
- **출고 게이트(sim)**: 판당 1장 클리어 **25~45%**, 첫 클리어까지 중앙 **≤3판**, 한 판 ≈ 5분, 소프트락 0.
- **결정 시각 10/4 18:00 KST**: 게이트 미달이면 지층을 끄고 **대체안** — Endless 해금 조건을 "128 도달"로 낮춤(0.5h). 부스트 일정은 미루지 않는다.

### 2-2. 첫 판 · 막지 않는 발견 (디자인 · AD 규격 · 기술, 5~6h)
- 첫 방문: Daily · 튜토리얼 · 챕터 인트로 · 공개 모달 없이 **Chronicles 1장 보드로 바로**. 첫 수가 곧 시작.
- 1~6단계 획득: 판을 멈추는 모달 대신 **칸 팝 + 장면 이름 · 연대 배너**(비차단). 모달은 1단계 첫 공개 · 11단계만.
- 사실과 다른 Daily 문구("3 attempts per day" · "today's leaderboard") 수정.

### 2-3. 광고 · 체크리스트 #10 (기술, 3h)
- Chronicles 게임오버 **CONTINUE (AD) 삭제** → CONTINUE 는 **별 결제만 · 판당 1회**(무료 1회 없음). 판당 상한은 디자인 r2 근거: 지층 + CONTINUE 1회 = 클리어 73~82%. 상한이 없으면 게이트(25~45%)가 의미를 잃는다. Daily 에 **무료 PLAY AGAIN**.
- 전면광고: 최소 90초 간격, 세션 첫 게임오버 · 메뉴로 나갈 때 · 장면 공개 직후 제외. **간격을 config 에 명시**(Bridge 2.3.0 자동 갱신으로 첫 광고 지연이 60→30초로 바뀐 것으로 보임 — 미실측).
- 리워드 광고는 ×2 같은 추가 보너스에만 남김.

### 2-4. 계측 · 안전 빌드 (기술, 7~8h)
- bridge config SaaS 리더보드 플랫폼에 `playgama_sandbox` 추가 + 일일 · Endless 최고점 재전송(꺼져 있던 동안의 기록 보존).
- `track()` 래퍼 → `bridge.analytics.send`(있을 때만): `scene_unlocked` · `run_ended` · `ad_offer` · `tutorial`, 공통 `gameVersion`. CDN 태그는 그대로(v2/stable 이 2.3.0 자동 제공).
- 빌드 게이트 이식: 외부 URL · 분석 도구 · 직접 localStorage · 인라인 스크립트 문법 · DEV 잔존. Playgama zip 에서 firebase.js · crazygames.js 는 no-op 스텁.
- iframe 포커스(`window.focus()` · `e.code`), 늦게 붙은 Bridge 에도 `game_ready` 1회.

### 2-5. 스토어 면 (AD · 운영, 5h · zip 밖)
- 커버 3종을 전용 키아트로(대각선 머지 사슬 카드 + 128px 에서 읽히는 로고), 스크린샷 5장을 v0.9.1 실제 화면으로, 설명의 "(new in 1.2)" · 옛 개발자 코멘트 제거, 공유 문구를 "Made with AI" 대신 큐레이션 포인트로.

### 2-6. 여유분 (시간이 남을 때만)
- 보드 가독성 최소 수리(AD, 3h): 타일 둥근 테두리 + 시대 색, 배경 2겹 → 1겹 α .25 + 비네트.

### 2-7. 게시 전 확인 (운영)
- 게시 페이지에서 실기: `leaderboards.type`(in_game 기대), `bridge.analytics` 존재, 첫 방문 → 보드 직행, CONTINUE 광고 없음, 광고 간격, 모바일 · 동작 줄이기 끔.
- 버전: `package.json` `0.9.1` ↔ `APP_VERSION 'v0.9.1'`(빌드 스크립트가 불일치를 막는다). 아카이브 이름 `earth-and-beyond-0.9.1-<hash>`. 릴리스 노트 `docs/devLog/Release_Note_v0.9.1.md`.

### 7-2. 빠진 위험
1. **재제출 오조작**: v0.9.1 업로드 뒤 제출 가능 상태가 될 수 있다. 측정 창 전에 제출하면 같은 판정을 다시 받는다 → 5장 3-1 에 반영.
2. **통제 밖 변수**: CDN `v2/stable` 은 우리 배포 없이 바뀐다(9/30 실제로 바뀜). 측정 창 동안 스냅샷마다 게시 페이지의 Bridge 버전을 기록한다. 바뀌면 리포트 구간을 나눈다.
3. **캠페인 겹침**: LH 런은 10/3 링크 추가 시점부터 최소 3일 → 10/6 밤까지 갈 수 있다. 10/7 시작 전 LH `get_sandbox_traffic` 이 RUNNING 이 아니고 EB `verdict.allowed: true` 인지 둘 다 확인한다(조직 단위 active-campaign capacity 는 미확인).
4. **analytics 를 볼 화면 미확인**: 보내기만 하고 우리는 못 볼 수 있다. 측정 창의 확실한 지표는 공개 plays + 게임 안 리더보드 분포다(LB STATS `?dev=1`).
5. **기존 진행과의 호환**: 1장 규칙(지층)과 첫 방문 흐름이 바뀐다. 기존 저장(갤러리 · 별)은 유지돼야 한다 → Storage 키 변경 0 을 확인한다.
6. **PC 부하**: 10/3 22:36 LH 링크 추가 · 10/5 저녁 LH 최종 스냅샷과 EB 무거운 빌드 · 브라우저 확인을 겹치지 않는다.
